# Android downloads

**[Download Walk with Jesus v0.001](https://github.com/raclob/walk-with-jesus/raw/refs/heads/main/downloads/walk-with-jesus-v0.001.apk)**

The same APK is included here as [walk-with-jesus-v0.001.apk](walk-with-jesus-v0.001.apk). On GitHub's file page, select **Download raw file**. GitHub's source ZIP also includes this APK.

Requires Android 7.0+ on an ARM64 phone. Download it, open it on your phone, and allow installation from your browser or file manager if prompted.

This test build uses the development signing key. Keep the app installed when updating to preserve its local data; uninstalling may remove reading progress and sermon notes. Store publication requires production signing.

Checksums are in [SHA256SUMS](SHA256SUMS). See the [release page](https://github.com/raclob/walk-with-jesus/releases/tag/v0.001) and [validation status](../docs/STATUS.md).
