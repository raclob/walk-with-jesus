# Walk with Jesus app

Expo SDK 54 / React Native application. Expo Router screens are in this folder's `app/` directory; the native Android project is in `android/`.

```sh
npm ci
npm run version:check
npm run typecheck
npm start
```

See [build instructions](../docs/BUILD.md), [versioning](../docs/VERSIONING.md), and [validation status](../docs/STATUS.md). Installable APKs live in [downloads](../downloads/).
